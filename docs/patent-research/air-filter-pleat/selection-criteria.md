# 가정용 공기청정기 필터 주름 형상: 특허 선별 기준과 과정

> 조사일: 2026-11-11 · 데이터베이스: KIPRIS (국내 특허·실용신안)
> 선별 결과는 [selected-patents.md](./selected-patents.md), 구성요소 비교는 [claim-chart.md](./claim-chart.md)에 있습니다.

## 1. 조사 목적과 범위

| 항목 | 내용 |
|---|---|
| 목적 | 가정용 공기청정기 필터의 **주름(플리츠) 형상**과 관련해, 제품 개발 시 검토해야 할 국내 특허를 찾는 것 (침해 위험 확인, FTO) |
| 포함 | 주름 치수(피치·높이·비율), 비균일 주름, 주름 간격유지 수단, 주름 배치 형태(평판·원통·V형), 주름과 다른 층·프레임의 결합 구조 |
| 제외 | 차량·엔진 흡기용, 산업·건물 공조용, 가습필터, 소재 조성만 다룬 특허, 제조설비 특허 |
| 한계 | 국내 문헌만 조사. 디자인권·해외 문헌은 아직 조사하지 않음 |

## 2. 선별 과정 (깔때기)

| 단계 | 방법 | 건수 |
|---|---|---|
| ① 넓은 키워드 검색 | 전문(全文)에서 `(주름+플리츠+절곡+접힘)*(필터+여과재)*(공기청정기+공기정화기)` | 3,339 |
| ② 분류코드 한정 | `IPC=[B01D46/52] * (공기청정기+공기정화기)` (B01D46/52: 주름·접힘 필터를 쓰는 입자 분리기) | 357 |
| ③ 청구항 조건 | `② * CL=[(주름+플리츠+절곡)*(피치+높이+간격+각도+형상+단면)]`. 청구항에 주름과 형상 요소가 함께 있는 문헌만 남김 | 113 |
| ④ 노이즈 제거 | 명칭·요약·IPC·출원인을 보고 용도와 주제가 다른 문헌 제외 (아래 3절) | 약 25 |
| ⑤ 법적 상태 분리 | 등록 / 공개 / 소멸·거절·취하로 나눔 | 등록 19 |
| ⑥ 청구항 판독 | 등록 19건의 독립항 원문을 읽고 주름 형상이 권리 요소인지 판단 | 형상 특허 12 |
| ⑦ 우선순위 평가 | 권리범위, 침해 입증 용이성, 제품 관련성, 존속기간, 패밀리로 등급 매김 (아래 4절) | ★ 3 |

**검색식을 이렇게 짠 이유**
- ①은 누락을 줄이려고 넓게 잡았습니다. 대신 항균·광촉매처럼 본문에 "주름"이 한 번만 나와도 걸려서 노이즈가 많습니다.
- ②의 분류코드는 "주름 필터"라는 기술 자체를 기준으로 거릅니다. 키워드 표현이 달라도 잡힙니다.
- ③에서 청구항(CL)에 조건을 건 이유는 권리범위가 청구항으로 정해지기 때문입니다. 본문에만 주름이 나오는 특허는 형상 특허가 아닐 가능성이 높습니다.

## 3. 노이즈 제거 기준 (113건 → 약 25건)

| 제외 사유 | 대략 건수 | 판단 근거 |
|---|---|---|
| 차량용 | 약 12 | 캐빈필터, 자동차 에어필터 (IPC B60H, 명칭) |
| 엔진 흡기용 | 약 8 | 영문 "air cleaner"가 "공기 청정기"로 번역된 문헌. 내용은 엔진 흡기 필터 카트리지 |
| 건물·산업 공조 | 약 8 | 환기청정기, 급기구, 지하역사, 철도 |
| 다른 제품 | 약 9 | 가습필터, 의류관리기, 조명, 창문, 방진망 |
| 제조설비 | 약 4 | 절곡장치, 헤파필터 제조설비 (형상이 아니라 공정 특허) |
| 소재 중심 | 약 10 | 부직포, 나노섬유, 탈취재 조성 |

> **주의 사례:** 키워드로는 "공기 청정기 조립체"인데 실제로는 엔진 흡기 필터인 문헌이 약 8건 있었습니다. 키워드 매칭만으로는 거를 수 없고, 문맥을 읽어야 걸러집니다.

## 4. 평가 기준

### 4-1. 1차 관문: 주름 형상이 독립항의 구성요소인가
- 독립항에 주름의 **형상·치수·배치·간격유지**가 구성요소로 들어 있으면 → 형상 특허
- 주름이 종속항이나 제조방법 청구항에만 부수적으로 나오면 → 제외
- 실제로 19건 중 7건이 여기서 탈락했습니다. 예를 들어 엘지전자 3건은 피인용이 높았지만 실제 권리는 케이스 분리 구조와 송풍 구획판이었습니다.

### 4-2. 우선순위 평가 항목

| 항목 | 보는 것 | 높게 평가하는 경우 |
|---|---|---|
| **권리범위** | 독립항 구성요소 수, 수치 한정의 폭, 형상 외 부가 구성 | 구성요소가 적고, 수치 범위가 시판 제품을 넓게 포함 |
| **제품 관련성** | 가정용 공기청정기 필터에 바로 적용되는가 | 원통형 HEPA, 평판 플리츠, 탈취필터 등 주력 부품 |
| **침해 입증 용이성** | 제품을 보고 해당 여부를 확인할 수 있는가 | 치수 실측으로 판단 가능 (성분 분석이 필요하면 낮게) |
| **법적 상태·존속기간** | 등록 여부, 출원일 + 20년 | 살아 있고 남은 기간이 김 |
| **패밀리 규모** | 해외 출원국 | US·CN·JP·WO 등 여러 나라 → 권리자가 중요하게 여김 |
| **회피 난이도** | 설계를 조금 바꿔 피할 수 있는가 | 피하기 어려울수록 위험도 높음 |

### 4-3. 참고만 하고 결정에는 쓰지 않은 지표
- **피인용 수:** 일반적으로 중요한 지표이지만, 이번 조사에서는 실제 관련성과 반대로 나왔습니다. 피인용 상위 3건(엘지)은 모두 형상과 무관했고, 가장 중요한 코웨이 특허는 2026년에 막 등록돼 피인용이 0건이었습니다. **최신 특허일수록 피인용이 낮게 나온다**는 점에 주의해야 합니다.

### 4-4. 등급 정의

| 등급 | 조건 |
|---|---|
| ★ S | 형상 특허 + 권리 존속 + (권리범위 넓음 또는 제품 관련성 높음) → 클레임 차트 작성 |
| A | 형상 특허 + 권리 존속 + 부가 구성 때문에 권리범위 좁음 → 목록 관리, 설계 시 참고 |
| P | 소멸·거절·취하 → 침해 위험 없음. 선행기술(무효자료)로 활용 |
| W | 공개 상태(심사 중) → 등록 여부 추적 |
| 제외 | 독립항에 주름 형상 없음, 또는 용도가 다름 |

## 5. 배운 점 (InPro 기능 설계에 반영할 것)
1. **정량 점수만으로는 선별할 수 없습니다.** 피인용·출원인 같은 메타데이터로 1차 정렬을 한 뒤, 반드시 청구항을 판독하는 단계가 있어야 합니다.
2. **키워드 검색은 번역·동음이의 문제로 노이즈가 많습니다.** 엔진 "air cleaner" 사례처럼 문맥 기반 분류가 필요합니다.
3. **권리범위를 좁히는 것은 대부분 형상 외의 구성입니다.** 소재, 프레임, 부가부품 같은 것들이라서, 형상 수치만 비교하면 위험을 과대평가합니다.
4. **청구항 원문 중 수식이 이미지로만 제공되는 경우가 있습니다.** 쓰리에이씨의 VK 수식이 그랬습니다. 공보 PDF를 함께 확인하는 경로가 필요합니다.

### 라벨링 방법
1. **규칙 라벨링:** 제목·요약·대표청구항·IPC의 키워드 빈도로 1차 분류합니다 (형상 단어 수 vs 소재 단어 수 vs 제어 단어 수).
2. **수동 검수 (115건):** 564건 전체 제목을 훑고, 가정용·형상 후보는 대표 청구항까지 읽어서 고쳤습니다. CSV의 `labeledBy` 열에 `수동검수`/`규칙`으로 표시되어 있습니다.
   - 공기청정기 **본체·케이스** 특허 (예: 엘지 원통형 케이스) → 형상이 아니라 `기타`
   - 엔진 흡기용 "air cleaner" 번역 문헌 → `차량용`
   - 용도가 본문에만 나오는 가정용 필터 (코웨이·쓰리에이씨 등) → `가정용`
   - 제목에 "장치"만 있는 절단·절곡 설비 → `제조`
3. **대표 청구항:** 1항이 삭제된 경우 남아 있는 첫 독립항을 넣었습니다. 요약이 없는 옛 문헌 5건은 요약 칸에 대표 청구항을 대신 넣고 그렇다고 표시했습니다.

### 한계
- 산업용 280건과 소재·제조 라벨은 규칙 위주라서 오분류가 일부 남아 있을 수 있습니다. **가정용·형상 36건은 전부 청구항을 확인했습니다.**
- 국내 문헌만 포함합니다.

## 7. 재현 방법
1. [KIPRIS](https://www.kipris.or.kr) 메인 검색창에 위 2절의 ③ 검색식을 그대로 입력합니다 (필드 검색 `IPC=[ ]`, `CL=[ ]` 지원).
2. 정렬을 "피인용횟수", 목록 수를 90개로 설정합니다.
3. 각 문헌의 상세보기 → 청구항 탭에서 독립항을 확인합니다.
