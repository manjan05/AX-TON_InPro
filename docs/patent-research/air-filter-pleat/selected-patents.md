### 1. 코웨이 · 10-2932356 「튜브형상의 절곡형 필터부재」

| 항목 | 내용 |
|---|---|
| 출원 / 등록 | 10-2019-0114123 (2019.09.17) / 2026.02.24 |
| 만료(추정) | 2039.09 |
| 패밀리 | US 12179137 B2, JP 7383800 B2, CN 114423508, WO 2021/054694 |
| 독립항 핵심 | 원통형 주름필터에서 **안쪽 주름 끝을 이은 선이 바깥쪽으로 함몰된 웨이브 형상으로 반복**됨. 외경 D 100~500mm, 두께 T1 = D/15~D/6, T2 = T1/2~T1/1.2 |
| 권리범위 | 중간. 수치 한정이 있지만 가정용 원통형 필터 대부분이 외경 범위 안에 들어감 |

| 회피 방향 | 안쪽 주름 끝을 정원으로 유지, T2/T1 비율을 범위 밖으로 설계 |
| 선정 이유 | 360° 원통형 공기청정기의 핵심 부품을 겨냥함. 2026년에 갓 등록돼 남은 존속기간이 길고, 해외 4개국에 패밀리가 있음 |
